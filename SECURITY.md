# Security policy

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/decryptus/mjcast/security/advisories/new).
Do not post security-sensitive details in public issues or pull requests.

Include the affected version or commit, impact and a minimal reproduction using
synthetic data. Remove credentials and personal data from attachments. Test only
systems you own or have permission to assess.

The current release is Python 2-only. Python 2 is end-of-life and the planned
Python 3 port is not yet available. A reporting channel does not imply that the
legacy runtime or every historical release receives security updates.
Coordinate investigation and disclosure in the private advisory discussion;
response and fix dates depend on the issue.
